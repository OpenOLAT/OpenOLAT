Page Pattern: Info Page New in 21.1.0

Info Page (Course and Implementation) New in 21.1.0

The redesigned info page of courses and implementations (template repository/ui/list/_content/info_page.html, styles .o_info_page in _repository.scss). Structure read from localhost. Two column wrappers hold the items: o_info_page_column_aside (thumbnail, get started, my course, events) and o_info_page_column_main (header, facts, sections, licence, rating). Each item has o_info_page_item plus its own class. The page reuses FactSheet (facts, "My course") and Sections (description blocks).

Layout: below $screen-sm-min the page is a one-column grid, the column wrappers get display: contents, and order sorts the items: thumbnail 1, header 2, get started 3, my course 4, benefits 5, facts 6, sections 7, events 8, licence 9, rating 10. On tablet width (sm) the thumbnail sits next to the header. From $screen-md-min the grid is 2fr 1fr: main column left, aside right. In print the page falls back to the one-column order and shows o_info_page_qrcode next to the header. For members (o_info_page_member) the "get started" block is reduced.

Accessibility: the title is the page h2, fact sheet and section titles are h3/h4, the rating block is a fieldset with legend. The share button is a dialog opener (aria-haspopup="dialog"). The example uses the real theme grid; at the width of this page it shows the two-column desktop layout.

Collapsible Sections New in 21.1.0

Sections New in 21.1.0

The Sections component (org.olat.core.gui.components.sections, SectionsFactory) renders a list of titled, collapsible blocks outside of forms. The info page of courses and implementations uses it for the description sections. Each section is a div.o_section > fieldset with a legend header and a Bootstrap collapse body. The header markup is the same as in the collapsible FormSection (SectionHeaderRenderer): h4.o_section_title.o_section_toggle with role="button", tabindex="0", aria-controls, aria-expanded and an sr-only "expand"/"collapse" label. functions.js handles click, Enter and Space with one delegated listener, so no script per instance is needed after AJAX updates. An open section has a bottom margin of 1em.
