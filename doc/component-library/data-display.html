Fact Sheet New in 21.1.0

Fact Sheet New in 21.1.0

A bordered box with a title and key facts in a responsive grid. Each fact has an icon in a tinted circle, a muted label, a value and an optional sub-value. A value can also be a component, for example a progress bar or a ComponentList of links. Optional footer buttons are right-aligned. A footer link with the class o_fact_sheet_footer_full (FactSheet.CSS_FOOTER_LINK_FULL_WIDTH) spans the full width. Java: FactSheetFactory in org.olat.core.gui.components.factsheet. Used on the info page of courses and implementations (InfoPageFactsController, InfoPageMyCourseController). GUI demo: Fact Sheets.

Layout: .o_facts is a CSS Grid with repeat(auto-fill, minmax($o-fact-min-width, 1fr)), so the number of columns follows the available width (320px per column by default). Variables in _config.scss: $o-fact-sheet-padding (20px), $o-fact-sheet-title-font-size (18px), $o-fact-icon-size (32px), $o-fact-icon-color ($brand-primary), $o-fact-icon-bg-color (10% of $brand-primary), $o-fact-value-font-size (16px). Styles are in _card.scss.

Accessibility: the title is an h3. The icons are decorative. The label comes before the value in the DOM, so screen readers read "Location, Lviv".

Scopes

Scope Selector

Category or time-period selector (GUI demo "Scopes", markup read from localhost). ScopeRenderer renders ul.o_scopes with one FormToggle per scope in the button presentation: button.o_toggle_button.btn.o_scope_toggle with role="checkbox" and aria-checked. The selected scope has o_toggle_on, the others o_toggle_off. The on and off text are both rendered; the hidden one has aria-hidden="true". With hints (o_scope_toggle_hints) each scope shows a second line o_scope_hint.

Timeline

Vertical Timeline

FlexiTable render type VERTICAL_TIMELINE (FlexiTableVerticalTimeLineRenderer). Rows are grouped by year and by day in nested ordered lists. Each item has a path column (top, center, bottom segment) and a content column; the content comes from the row renderer. An expandable row adds o_vertical_timeline_item_details and a button.o_button_details. Styles: _vertical_timeline.scss and _table.scss.

Countdown

Countdown Timer

CountDownComponent (CountDownComponentRenderer) renders a plain <span id="o_c{id}"> that contains the remaining number, or an i18n text with the number (singular and zero keys are supported). The polling updates the span. The theme has no countdown classes; the surrounding template gives the context, as in the example.
