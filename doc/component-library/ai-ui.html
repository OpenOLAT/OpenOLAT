AI Pulse Icon

AI Pulse Icon (Idle)

Animated SVG indicator for AI features. The inline SVG lives in core/commons/services/ai/ui/_content/ai_pulse_icon.html; templates include it with #parse(...) and set $aiPulseExtraClass for state and size. The SVG has role="img" and aria-label="OpenOlat AI" (override with $aiPulseAriaLabel). Idle state: only the sparkles twinkle slowly. Sizes: o_ai_pulse_xs 32px, o_ai_pulse_sm 40px, o_ai_pulse_md 64px, o_ai_pulse_lg 80px (default), o_ai_pulse_xl 120px. Styles: _ai_pulse.scss. Standalone files for <img>: static/images/openolat/o_ai_pulse_icon_static.svg and o_ai_pulse_icon_active.svg.

AI Pulse Icon (Active) and Badge

o_ai_pulse_active plays the working animation: breathing, halo, glow and travelling flares. Templates set it while an AI job runs, for example during question generation and essay correction. o_ai_pulse_badge wraps the icon in a round $brand-primary badge. With prefers-reduced-motion: reduce all animations stop and a resting frame stays.

AI Job Status

Waiting Overlay and Status Messages

While an AI job runs, the page shows the active pulse and a waiting text in a live region (role="status" aria-live="polite"), so screen readers announce the state. A hidden poll link is clicked by a timer to fetch the result. Question pool: o_ai_questions_overlay. Its template comment says the overlay stays hidden until the fieldset has o_ai_questions_generating and then covers the form. The light theme has no rule for these two classes (checked on 21.1-SNAPSHOT), so the example shows it inline with inline styles. Quiz element: o_ai_generation_stalled (muted) and o_ai_generation_failed (warning box) report problems. Essay correction: o_essay_ai_correction_overlay with o_essay_ai_correction_message.

AI Essay Feedback

AI Correction Box with Annotated Paragraphs

Essay correction in the content editor quiz (ceditor/ui/_content/quiz_run.html, AiEssayFeedbackViewFlattener). The box has a title with the small pulse icon, an assessment block with a radial progress and a text summary, and the learner text in blockquote.o_ai_essay_direct paragraphs. Inline marks: o_ai_mark_correct (green tint), o_ai_mark_ambiguous (yellow tint), o_ai_mark_wrong (red tint with wavy underline, solid with reduced motion); the comment is in title. Per-paragraph feedback is an aside.o_ai_paragraph_feedback between the blockquotes. The detailed feedback uses the assistance accordion markup (o_assistance_accordion o_essay_ai_correction_detailed). Styles: _ai_feedback.scss, _contenteditor_quiz.scss.

Accessibility: the mark colour alone carries the meaning, and the comment is only in title, which keyboard and screen reader users do not get reliably. See the accessibility chapter of the frontend reference.
