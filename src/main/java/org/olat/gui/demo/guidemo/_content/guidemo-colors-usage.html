Sources

The palette has one source: $o-palette in the Sass of the theme. Everything else is computed from it.

WhereWhat
themes/light/_palette.scss$o-palette (14 hues × 10 steps), $o-palette-bright, the computed roles $o-swatches, the legacy alias tables and the functions o-palette(), o-swatch-alias-color(), o-swatch-alias-on-white(), o-swatch-alias-selector()

1. A component that shows a chooser color

Put the stored class or the swatch class on the element. Read the role tokens in the module. Write the rule once for all colors.

<div class="o_my_item o_swatch_blue">...</div>
<div class="o_my_item o_swatch_blue o_swatch_dark">...</div>
<div class="o_my_item o_cal_navy">...</div>   <!-- legacy class, same tokens -->
// modules/_my_module.scss
.o_my_item {
	background: var(--o-sw-bg);
	color: var(--o-sw-fg);
	border: 1px solid var(--o-sw-border);
}
.o_my_item.o_my_soft {
	background: var(--o-sw-soft-bg);
	color: var(--o-sw-soft-fg);
	border-color: var(--o-sw-soft-border);
}
.o_my_label { color: var(--o-sw-text); }   // text on white

2. A fixed palette color in Sass

$o-my-color: o-palette("blue", 500);                         // a primitive
$o-my-fg: map.get(map.get($o-swatches, "blue"), "fg");       // a role of a hue
$o-my-cat: o-swatch-alias-color("o_colcat_red");             // fill of a legacy class
$o-my-label: o-swatch-alias-on-white("o_colcat_orange");     // text on white, close to the fill
$o-my-text: o-on-color($o-my-bg, (#FFFFFF, o-palette("blue", 900)));  // build fails below 4.5:1

3. A palette color in plain CSS or content

.o_my_chart_line { stroke: var(--o-green-500); }

4. A palette color in Java

Use Java only when a hex value is needed outside the browser CSS, e.g. a baked SVG or a chart library.

Swatch swatch = colorService.resolve(storedValue, ColorFamily.CALENDAR);  // "blue", "o_cal_blue" -> blue, dark
String fill = colorService.getBackgroundColor(swatch, "#717171");
Palette palette = colorService.getPalette();                               // palette of the current theme
String text = palette.fg(swatch);                                          // white or step 900
String onWhite = palette.text("blue");                                     // step 500

Rules

  • Do not write chooser hex values in modules or Java. The only hex values are in $o-palette.
  • Do not store hex values. Store the key or the legacy class, the alias maps resolve it to a swatch.
  • Do not use o-a11y-color() on chooser colors. It shifts the hue (gold becomes olive). Use o-on-color() or o-swatch-alias-on-white().
  • A new chooser key needs an alias entry in _palette.scss and in ColorServiceImpl. Keep both tables in sync.
  • Every text on a fill has 4.5:1, also for large and bold text. Borders of fills have 3:1 on white.

Client themes

  • A client theme can override the values of $o-palette in its config before the import of the light theme. It must keep all 15 hue names, the alias tables need them. Every step needs a foreground with 4.5:1, otherwise the compile fails.
  • OpenOlat reads the palette from the compiled theme.css of the active theme. Badges and report charts follow the client palette.
  • A theme without the --o-{hue}-{step} properties, e.g. a theme compiled before the palette, uses the palette of the light theme, without theme colors.
  • compiletheme.sh compiles the theme and writes nothing else.

Theme colors

The brand colors of a theme, in addition to the 14 hues. Default: one color, $brand-primary. Needs Dart Sass 1.79.0 or later.

// client config, before the import of the light theme
$o-theme-colors: ($brand-primary, $brand-accent, #0090C5);
  • themes/light/_palette_theme.scss generates the 10 steps per color and appends theme1 ... themeN to $o-palette and $o-swatches.
  • CSS: --o-theme{n}-{step}, --o-theme{n} (the solid fill) and .o_swatch_theme{n}.
  • Java: Palette.getThemeColors() and ColorService.getThemeColors() return only the colors the theme defines. resolve("theme3") returns theme1 when the theme has fewer colors.
  • Store the key theme{n}, never the hex value: the object then follows the theme.
