A swatch is the set of roles of one hue. The class .o_swatch_{hue} sets the role tokens as CSS custom properties, the modifiers .o_swatch_dark, .o_swatch_tint and .o_swatch_light replace the solid fill roles. The samples run from the darkest fill on the left to colored text on the right. Components read the tokens and set no colors of their own. The contrast ratios below are measured in the browser from the computed colors; a red outline marks a value below 4.5:1.
