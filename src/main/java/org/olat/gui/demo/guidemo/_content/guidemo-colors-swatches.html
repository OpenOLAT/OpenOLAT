A swatch is the set of roles of one hue. The class .o_swatch_{hue} sets the role tokens as CSS custom properties, the modifiers .o_swatch_dark, .o_swatch_tint, .o_swatch_light and .o_swatch_soft replace the solid fill roles (.o_swatch_soft with the soft roles). The samples run from the darkest fill on the left to colored text on the right. Components read the tokens and set no colors of their own. The contrast ratios below are measured in the browser from the computed colors; a red outline marks a value below 4.5:1.

Table styles

The table style of the content editor and the HTML editor, one per hue and theme color: table.b_{key}. The pure hue gray is b_gray_hue, because the stored style b_gray is the slate table.
