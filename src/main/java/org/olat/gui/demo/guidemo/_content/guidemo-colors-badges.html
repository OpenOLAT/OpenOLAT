Badges and status labels show the meaning of a status, not a colour. Each status class belongs to one of 8 semantic states. The state defines the hue, the style defines the weight. A new status uses the state class o_state_<name> that matches its meaning (OO-10042). The existing status classes keep their names; $o-state-wiring in themes/light/modules/_states.scss assigns each of them a state and a style. All badges on this tab use the classes of the current theme. The numbers under each badge are measured in the browser: text on its background, and the border on white. A red outline marks text below 4.5:1, a dashed red outline a border below 3:1.
