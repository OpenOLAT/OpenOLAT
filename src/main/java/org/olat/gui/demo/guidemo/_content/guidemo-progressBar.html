Basic usage

Segments are the only data. A single value is one segment, the total is the sum of all segments.

ProgressBar progressBar = ProgressBarFactory.createProgressBar("progressBar", mainVC);
progressBar.setMax(100);
ProgressBarFactory.setValue(progressBar, 25, BarColor.neutral);
$r.render("base")

Label formats

progressBar.setLabelFormat(LabelFormat.none); // default
$r.render("format-none") 
progressBar.setLabelFormat(LabelFormat.percent);
$r.render("format-percent") 
progressBar.setLabelFormat(LabelFormat.value);
$r.render("format-value") 
progressBar.setLabelFormat(LabelFormat.percentAndValue);
$r.render("format-both") 
progressBar.setMax(125);
progressBar.setUnitLabel("MB");
progressBar.setInfo("Disk usage");
progressBar.setLabelFormat(LabelFormat.percentAndValue);
$r.render("format-unit") 
progressBar.setNoMax(true); // the value label has no "/max"
progressBar.setUnitLabel("MB");
progressBar.setLabelFormat(LabelFormat.value);
$r.render("format-nomax")

Width

A horizontal bar fills its container. Inline bars have a fixed width. Limit the width with the CSS of the context or a CSS class:

progressBar.setCssClass("o_progress_quota");

Render styles and sizes

The label is rendered inside medium and large bars and after small and inline bars. Radial and pie render segments as arcs and markers as lines.

progressBar.setRenderStyle(RenderStyle.horizontal | radial | pie);
progressBar.setRenderSize(RenderSize.inline | small | medium | large);
progressBar.setLabelFormat(LabelFormat.percent);
#foreach($size in ["large", "medium", "small"])

$size

$r.render("horizontal-$size")
$r.render("radial-$size")
$r.render("pie-$size")
#end

Colors

The color belongs to the segment. Radial and pie use the color of the first segment.

ProgressBarFactory.setValue(progressBar, 65, BarColor.success);
progressBar.setSegments(List.of(new Segment(65, BarColor.success, "o_my_css_class", "label")));
#foreach($color in $colors)
$color.name() $r.render("hor-$color.name()")
#end
#foreach($color in $colors)
$r.render("rad-$color.name()")
#end

Stacked bars and markers

Each segment has a text label, shown as tooltip and used for the accessible name of the bar (role="img").

progressBar.setMax(10);
progressBar.setAriaLabel("Members"); // name: "Members: 6 active, 2 pending of 10"
progressBar.setSegments(List.of(
		new Segment(6, BarColor.success, "active"),
		new Segment(2, BarColor.warning, "pending")));
$r.render("stacked") 
progressBar.setMax(20);
progressBar.setMarkers(List.of(new Marker(10, "minimum"), new Marker(16, "maximum")));
$r.render("markers") 
// Segments that fill the bar keep the rounded corners with markers
progressBar.setRenderSize(RenderSize.small);
progressBar.setMarkers(List.of(new Marker(5, "minimum")));
$r.render("markers-full") 
// Radial and pie draw markers as lines from the center
progressBar.setRenderStyle(RenderStyle.radial | pie);
progressBar.setMarkers(List.of(new Marker(50, "minimum"), new Marker(80, "maximum")));
$r.render("markers-radial")
$r.render("markers-pie")
$r.render("markers-radial-small")
This is within $r.render("markers-radial-inline") some text
// Radial and pie draw each segment as an arc
progressBar.setMax(20);
progressBar.setRenderStyle(RenderStyle.radial | pie);
progressBar.setSegments(List.of(

		new Segment(4, BarColor.warning, "pending"),

progressBar.setMarkers(List.of(new Marker(10, "minimum"), new Marker(16, "maximum")));
$r.render("segments-radial")
$r.render("segments-pie")

Accessibility

A bar with one segment has role="progressbar" with aria-valuenow, aria-valuemin and aria-valuemax. Its name is the aria label, else the segment label, else "Progress". Set a name if "Progress" does not describe the bar:

progressBar.setAriaLabel("Course progress");
$r.render("aria-label")

Hide a decorative bar if the same information is shown as text:

progressBar.setAriaHidden(true);
$r.render("aria-hidden")

Animated

progressBar.setProgressAnimationEnabled(true);
$r.render("hor-anim")
$r.render("rad-anim")

Table cells

The ProgressBarCellRenderer uses the same markup. A Number cell value is one segment with max 1. Override createProgressBar(Object) for stacked bars.

new ProgressBarCellRenderer(RenderStyle.horizontal, RenderSize.small, LabelFormat.percent, BarColor.neutral)
$r.render("table")
