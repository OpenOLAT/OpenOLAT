OpenOlat package overview

org.olat is the root package of OpenOlat. The framework lives in {@link org.olat.core}. The other top-level packages hold the domain logic. A package usually contains a manager or service layer, a ui sub-package with the controllers, and _spring, _i18n and _content folders for Spring configuration, translations and Velocity templates. The architecture is described in doc/openolat-architecture.md in the source tree.

Top-level packages

{@link org.olat.core}The framework: GUI, dispatching, persistence, configuration, logging, VFS, i18n, services. See {@link org.olat.core}.
{@link org.olat.course}Courses: structure, course elements (course.nodes), run and editor, assessment, archiving.
{@link org.olat.dispatcher}Top-level request dispatchers.
{@link org.olat.fileresource}File based learning resource types.
{@link org.olat.group}Business groups, their members and areas.
{@link org.olat.gui}Top navigation, footer and user tools, plus the GUI demo ({@link org.olat.gui.demo}).
{@link org.olat.home}The personal home site: settings, calendar, personal files.
{@link org.olat.ims}IMS standards: content packaging (ims.cp), QTI 2.1 tests (ims.qti21), LTI 1.1 and 1.3.
{@link org.olat.instantMessaging}Chat and instant messaging.
{@link org.olat.ldap}LDAP login and user synchronization.
{@link org.olat.login}Login, authentication providers, OAuth, passkeys, password policy.
{@link org.olat.modules}Feature modules, one sub-package each, for example ceditor, cemedia, portfolio, qpool, curriculum, lecture, taxonomy, catalog, forms, quality, video, wiki, fo, bigbluebutton, teams, zoom, openbadges, selectus.
{@link org.olat.note}Personal notes.
{@link org.olat.portal}Portal (portlet) framework of the home page.
{@link org.olat.properties}Generic key/value properties stored in o_property.
{@link org.olat.registration}Self-registration of new users.
{@link org.olat.repository}Learning resources (repository entries): lifecycle, access, search, authoring.
{@link org.olat.resource}OLAT resources, access control and booking (resource.accesscontrol), references between resources.
{@link org.olat.restapi}The REST API.
{@link org.olat.search}Full-text search based on Lucene: indexers, searcher, UI.
{@link org.olat.shibboleth}Shibboleth (SAML) login.
{@link org.olat.social}Social features such as share links.
{@link org.olat.upgrade}Upgrade steps that run at startup (OLATUpgrade classes).
{@link org.olat.user}User profile, user properties, user settings and user management.
{@link org.olat.util}Utilities of the root level (logging helpers).

{@link org.olat.core.id}Identity interfaces, OLATResourceable and business paths (core.id.context).
{@link org.olat.core.util}Utilities: VFS, events, coordination and locks, caches, i18n, mail, HTTP client.
{@link org.olat.core.logging}Logging and user activity logging.
{@link org.olat.core.extensions}Extension points for menus and actions.
{@link org.olat.core.helpers}Settings and other helpers.
{@link org.olat.core.servlets}The main servlets.

How to's

  • Need code samples? Set olat.debug=true and guidemo.enabled=true in olat.local.properties, log in as administrator and look for the "gui demo" tab ({@link org.olat.gui.demo}), which shows you plenty examples on how to do different stuff in OLAT and you can view the source code directly with a click in your browser. Check it out!

How to create a direct link ?

E.g. Create a direct link to a course-node.
String nodeUrl = "[" + OresHelper.calculateTypeName(CourseNode.class) + ":" + node.getIdent() + "]";
see {@link org.olat.core.id.context}

How to show status messages ?

Show a translated text as info-message at the top of UI :
this.getWindowControl().setInfo(translator.translate("found.no.result.try.fuzzy.search"));
