Movie viewer plugin for TinyMCE

This package adds the TinyMCE plugin olatmovieviewer to the rich text editor. With it an author embeds a video or an audio file in HTML content. The player is BPlayer (static/movie/player.js), an HTML5 player based on MediaElement.js. The plugin supports these providers: plain HTTP files, YouTube, Vimeo, nanoo.tv, and RTMP streams through a streamer.

Classes

  • {@link org.olat.core.gui.components.form.flexible.impl.elements.richText.plugins.olatmovieviewer.OlatMovieViewerPlugin}: extends {@link org.olat.core.gui.components.form.flexible.impl.elements.richText.plugins.TinyMCECustomPlugin}. getPluginParameters(Locale) passes the transparent placeholder image, the player script (movie/player.min.js, or movie/player.js in debug mode) and the manual URL manual_user/resource_video/ to the JavaScript plugin.
  • {@link org.olat.core.gui.components.form.flexible.impl.elements.richText.plugins.olatmovieviewer.TinyDispatcher}: dispatcher on the path /tiny/ (bean tinywebbean in core/dispatcher/_spring/dispatcherContext.xml). For an authenticated user it asks the nanoo.tv oEmbed service for the width and height of a video (parameter nanooId) and returns them as JSON.

Configuration

  • richText/_spring/richTextCorecontext.xml registers the plugin as a custom plugin.
  • TinyConfig.enableImageAndMedia() enables the plugin. disableImageAndMedia() and disableMedia() disable it.
  • When the plugin is active and the media server mode of MediaServerModule is not allowAll, RichTextConfiguration.appendMediaRestrictionCode(...) adds the restriction warning error.media.restricted to the editor.

Client side

The JavaScript plugin lives in static/js/tinymce4/tinymce/plugins/olatmovieviewer/. The screenshot in doc-files/ shows an old version of the dialog.
