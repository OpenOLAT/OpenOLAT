Math editor plugin for TinyMCE

This package adds the TinyMCE plugin olatmatheditor to the rich text editor. With it an author writes formulas in LaTeX syntax. The editor shows a live preview.

Classes

  • {@link org.olat.core.gui.components.form.flexible.impl.elements.richText.plugins.olatmatheditor.OlatMathEditorPlugin}: extends {@link org.olat.core.gui.components.form.flexible.impl.elements.richText.plugins.TinyMCECustomPlugin}. getPluginParameters(Locale) passes the transparent placeholder image and the manual URL manual_user/basic_concepts/Math_formula/ (from HelpModule) to the JavaScript plugin.

Configuration

  • richText/_spring/richTextCorecontext.xml registers the plugin as a custom plugin.
  • A form enables the plugin with RichTextConfiguration.enableMathEditor() and disables it with disableMathEditor() (both delegate to TinyConfig).
  • mathjax.cdn in olat.properties (default //mathjax.openolat.org/mathjax/4.0-latest/) sets the MathJax library that renders the formulas. When the value is empty, RichTextConfiguration removes the plugin from the editor.
  • mathlive.cdn (default //mathjax.openolat.org/mathlive/v2/mathlive.min.js) sets the MathLive library. RichTextElementComponent loads it for the visual formula input.
  • mathjax.config and mathjax.markers control the MathJax configuration and the delimiters \( \), \[ \] and $$. WebappHelper holds the values (see core/util/_spring/utilCorecontext.xml).

Client side

The JavaScript plugin lives in static/js/tinymce4/tinymce/plugins/olatmatheditor/. It stores a formula as an element with the class math in the HTML. The screenshots in doc-files/ show the old jsMath dialog and are outdated.
