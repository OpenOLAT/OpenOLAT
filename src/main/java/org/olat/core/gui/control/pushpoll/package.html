Window commands for the AJAX response

This package holds one class, {@link org.olat.core.gui.control.pushpoll.WindowCommand}. A WindowCommand pairs a {@link org.olat.core.gui.control.winmgr.Command} with the {@link org.olat.core.gui.control.WindowBackOffice} of the browser window it is meant for.

OpenOlat renders the full page only on the first request. Later requests are AJAX requests. After each request {@link org.olat.core.gui.control.winmgr.AjaxController} asks the window for its dirty components (Window.handleDirties()). The window returns them as a command. The controller wraps this command and other commands, for example a redirect from {@link org.olat.core.gui.control.winmgr.CommandFactory}, in WindowCommand objects. It then writes them as one JSON response. The browser replaces the matching DOM fragments.

WindowBackOfficeImpl.sendCommandTo(...) uses the same path to push a command to the window. See the package org.olat.core.gui.control.winmgr for the classes that do the work.
