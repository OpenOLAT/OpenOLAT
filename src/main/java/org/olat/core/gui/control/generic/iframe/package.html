Display of HTML content in an iframe

This package shows HTML content from a file system or VFS directory in an iframe. Single pages, content packages, SCORM, the document course element and the impressum pages use it. The iframe resizes itself to the height of the content, so the user normally sees no iframe scrollbars.

Classes

  • {@link org.olat.core.gui.control.generic.iframe.IFrameDisplayController}: renders the iframe (_content/index.html). setCurrentURI(String) loads a new start page. Setters control download, height, encoding and custom header content.
  • {@link org.olat.core.gui.control.generic.iframe.IFrameDeliveryMapper}: a {@link org.olat.core.dispatcher.mapper.Mapper} that delivers the files of the directory. For HTML pages it injects JavaScript into the page: js/openolat/iframe.js, optionally jQuery, and the iFrameResizer library. {@link org.olat.core.gui.control.generic.iframe.SerializableIFrameDeliveryMapper} is the serializable variant. The controller uses it when IFrameSettings asks for a persisted mapper.
  • {@link org.olat.core.gui.control.generic.iframe.DeliveryOptions}: the delivery options an author sets for a resource: standard mode, jQuery, glossary, OpenOlat CSS, height (auto, ignore or a pixel value), content and JavaScript encoding, and inheritance from the parent. {@link org.olat.core.gui.control.generic.iframe.DeliveryOptionsConfigurationController} is the form for these options (used for example in the single page, CP, SCORM and structure course element editors).
  • {@link org.olat.core.gui.control.generic.iframe.IFrameSettings}: the security settings of one iframe: content security policy, strict sanitizing, delivery from the content domain, mapper persistence and randomization, iFrameResizer on or off. IFrameSettings.sanitize() and IFrameSettings.secure() are presets. With useContentDomain and Settings.isContentDomainNameEnabled() the mapper serves the content from the separate content domain (server.content.domainname).
  • {@link org.olat.core.gui.control.generic.iframe.NewIframeUriEvent}: fired to the parent controller when the user navigates inside the iframe.

Inline navigation

A click on a link inside the iframe goes to the mapper, not to the controller. A mapper cannot fire events. The injected JavaScript therefore calls newUriEvent(uri) (_content/event.html). This sends a command to IFrameDisplayController. The controller updates its current URI and fires NewIframeUriEvent. A parent, for example the content package controller, then selects the matching node in its menu tree.

The sequence diagrams in doc-files/ show the normal load and the inline click in an older version of the framework.
