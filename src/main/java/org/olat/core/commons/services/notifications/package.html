Overview description of notifications package.

Subscription email

Notifications module is stated by Spring in a scheduler context. See org/olat/core/commons/services/scheduler/_spring/schedulerContext.xml

Normally email are sent once a day but you can configured cron style syntax in the spring config. See: org/olat/core/commons/services/notifications/_spring/notificationsContext.xml (property notification.cronjob.expression)
